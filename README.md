# CampusAI 🎓

CampusAI is an AI-powered Smart Campus Grievance & Help Desk System designed to simplify complaint management in educational institutions.

Students can submit complaints, track their status, and receive updates, while administrators can efficiently manage, prioritize, and resolve issues. The system uses Machine Learning to automatically classify complaints and predict urgency, enabling faster and smarter campus operations.

## 🚀 Features

- Student registration and authentication
- Submit and track campus complaints
- AI-based complaint category prediction
- AI-based urgency/priority prediction
- Admin and staff dashboards
- Complaint status management
- File/image upload support
- Notifications and activity tracking
- Analytics dashboard
